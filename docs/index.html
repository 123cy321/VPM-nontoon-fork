一键添加（VCC）

▶ 添加到 VCC

点按钮后 VCC 会弹出「添加仓库」确认框，确认即可。
没反应说明你没装 VCC（或系统没注册 vcc: 协议）—— 用下面任意一种方式添加。

ALCOM / VCC 手动添加

在 ALCOM（或 VCC）里找到「添加仓库 / Add Repository」，粘贴这个 listing 地址：

https://123cy321.github.io/VPM-nontoon-fork/vpm.json

注意是 vpm.json 的地址，不是 .zip 的地址。

或者：直接复制深链

vcc://vpm/addRepo?url=https://123cy321.github.io/VPM-nontoon-fork/vpm.json

复制到浏览器地址栏回车，效果与上面的按钮相同。
