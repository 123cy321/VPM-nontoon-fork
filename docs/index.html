一键添加（VCC）

▶ 添加到 VCC

点按钮后 VCC 会弹出「添加仓库」确认框，确认即可。
没反应说明你没装 VCC（或系统没注册 vcc: 协议）—— 用下面任意一种方式添加。

ALCOM / VCC 手动添加

在 ALCOM（或 VCC）里找到「添加仓库 / Add Repository」，粘贴这个 listing 地址：

https://catandling.github.io/VPM-nontoon-fork/vpm.json

注意是 vpm.json 的地址，不是 .zip 的地址。

或者：直接复制深链

vcc://vpm/addRepo?url=https://catandling.github.io/VPM-nontoon-fork/vpm.json

复制到浏览器地址栏回车，效果与上面的按钮相同。

可用版本

版本要点
0.3.10 / 工具 0.5.20.3.10 起才带 NTRTDepth.shader —— 0.3.9 的包里没有它，所以装了 0.3.9 的人 ⑥ 实时自阴影根本跑不起来（组件找不到 NonToon/NTRTDepth 会自己 disable）；并补 ⑥ 的整套 _SelfLightRt* 属性与 PCSS 通路。工具包 0.5.2：Modular Avatar 成为必需依赖，需要菜单的功能一律声明式安装，旧的「直接写你的 FX 控制器 / ExpressionParameters / ExpressionsMenu」回退路径已整段删除。游戏内菜单改为子菜单 + 4 个独立控制项（光照下限 / 光照上限 / 阴影强度 / 阴影开关），合计 25 bit，不再是「一个不明不白的轮盘」；阴影开关默认关。新增环境光色温探测：在着色器自己的色温曲线上反推（往返精确 0 K），并如实标注偏绿/偏品红的环境色是色温表达不了的（避免「暖色地图里自己是一盏冷光」）
0.3.9 / 工具 0.5.1修复 PCSS 软影宽度随烘焙分辨率变化：半径以纹素定义、包围盒与分辨率无关 ⇒ 256²→512² 世界宽度只剩 71%（1024² 只剩 57%）。判别实验证明漂移由半径驱动、且实际半影对纹素半径超线性（≈R^1.55），故按实测标定的 g(s)=s^0.8 换算半径并同步按 s² 补采样数；256² 输出与旧版逐像素一致（实测最大差 1/255），512²/1024² 已一致（实测 86%）。另修文档中「调高分辨率会更软」这条方向写反的建议
工具 0.5.0新增 ④ 自带光照与阴影（不需要地图光源）：组件自带虚拟光方向，一键配好「私有光 + 亮度下限 + 烘焙自阴影」——实测虚拟光烘焙与真 Light 同方向逐像素一致（最大差 0.00001）。新增 ⑤ 亮度调整（构建时固定 / 游戏内可调）：装了 Modular Avatar 就走非破坏路径（只生成独立资产 + 挂 MA 四个组件，不动你原有的 FX 控制器/参数/菜单，删组件即回滚），并用真实 MA 1.18.1 + NDMF 跑完整构建验证（45 项断言）。另修「关掉自阴影仍会烘焙并挂贴图」的 bug
0.3.8 / 工具 0.4.9修 PCSS 软阴影的边界 bug：深度图采样器的寻址模式实测是 Repeat（与贴图导入设置无关），未夹紧的取样点会读到深度图对面的纹素 —— 贴边一圈的阴影被冲淡（遮挡 1.000 → 0.642），对面是几何时还会凭空多出一条假阴影。现夹到纹素内部（只夹到 [0,1] 不够：Repeat 会把 u = 1.0 映射回纹素 0）。另更正「PCSS 是固定循环」「Quest 无动态循环」两处不实描述，补充软影宽度随烘焙分辨率变化等注意事项
工具 0.4.8新增 ③ 亮度自适应与防煤插件：场景光照诊断 + 「模拟全黑地图」+ 亮度预设（抬高亮度下限即防煤、零采样代价）+ 生成 VRChat 可调参数（径向菜单驱动 _LightMinLimit）+ 上传前清理
0.3.7修 .meta 缺失（重装/换机后组件不再变 Missing Script）、修默认语言下汉化不生效（中文 Windows 默认 zh-CN，以前 165 条里只有 35 条中文，现在 117 条）
0.3.6两类光源组件（① 不用改材质 / ② 需材质启用）、光源编号（材质指定只接受哪一路光）、屏蔽环境光、阴影颜色 / 阴影强度遮罩 / 可自备阴影贴图；修自有光被每盏附加光各加一遍
0.3.5着色器 UI 修复（10 个内部管线属性 [SCHide] 不再上面板、按光源/环境匹配/自阴影分组）；新增色温与环境光匹配；修「自有光被每盏附加光各加一遍」的过曝 bug
0.3.4把消耗压回去：PCSS 默认档位 中(36)→低(20 采样)、接收遮罩默认不采样、强度 0 时一次都不采；组件面板直接显示每像素采样预算
0.3.3修 只由它照亮 没真正关掉世界环境光的 bug（排他通路从 customlight 挪到 modifylight；顺带清 env、接管渐变方向）→ 无环境光/环境光乱来的地图里 avatar 长相一致；工具包加独立的 Avatar 光源插件
0.3.2修「材质面板还有一半英文」：ShaderCore 0.1.12 起不再附带 zh-Hans.po，导致 Main / 贴图 / 共享遮罩 / 共享渐变 / 法线贴图 / 粗糙度 / 裁剪阈值 / 选择模块 / 创建贴图 这些内置项永远是英文。现在由本包在缺失时自动补齐（不覆盖上游自带）
0.3.1性能不再当约束：PCSS 画质四档（20/36/60/96 次采样）、烘焙上限 2048；SelfLight 新增 实时光源模式（真 Spot Light，姿势实时的自阴影，Culling Mask 默认只照 PlayerLocal）
0.3.0补齐汉化（模板测试/渲染/混合那一整块 + 模块标题 + 右键菜单）、SelfLight 加 PCSS 软阴影、lilToon 逐像素阴影遮罩可转换
0.2.0新增 SelfLight（自有光源 + 烘焙自阴影）、Emission / ShadowColor 模块被转换器用上
